PadraoAI

Padrão de desenvolvimento com IA (XP, TDD, segurança, economia de tokens) para adotar em qualquer projeto: regras curtas com o porquê, um time de papéis para Claude Code, Antigravity e dsh, e hooks que tornam as regras reais. Para quem mantém o padrão e para o agente que trabalha neste repo.

v0.1.0 · Node 22, ESM, zero dependências 17 inegociáveis 5 papéis × 3 CLIs distribuído por npx github: (sem npm registry) CI: lint-contexto + npm test

Fontes: package.json, inegociaveis.md, agents/, LEIA-ME-AGENTE.md, .github/workflows/ci.yml.

O projeto em 30 segundos

1

Instala

npx github:Pa1loh/PadraoAI init copia templates/ sem sobrescrever, gera os papéis e põe inegociaveis.md + ADOTAR.md em docs/padraoai/ (bin/padraoai.mjs).

2

Adota

O agente segue ADOTAR.md: AGENTS.md ≤120 linhas como fonte única, hooks, CI, ADRs. Verifica com evidência.

3

Escreve a issue

/issue-criar escreve issue pronta para agente; o hook templates/.claude/hooks/valida-issue.sh barra issue sem as seções.

4

Executa

/issue N: branch → analista → plano → TDD → revisor → PR. Ou /proximas: lote de até 3 em worktrees. Merge e deploy são humanos.

5

Kaizen

Falha do agente vira teste, hook, linha no AGENTS.md ou ADR (inegociável 17); templates/docs/agent-log.md registra engine e custo por issue.

Pode / Não pode

Pode

  • Editar agents/, skills/, templates/, rules/, bin/ com teste em test/ e npm test verde.
  • Criar skill quando há uso recorrente (inegociável 11), no lugar certo (núcleo × extras).
  • Rodar hooks e testes localmente; abrir PR. Merge e deploy são do mantenedor.
  • Exemplos fictícios em templates e testes, marcados como tais.

Não pode

  • Segredo, token, host, IP ou dado pessoal em arquivo do repo: ele é open source. Só variável de ambiente/cofre; logar a ausência, nunca o valor (inegociável 5).
  • Copiar extras/infra-pessoal/ para template ou projeto que adota.
  • Editar a cópia gerada (.claude/agents/, .agents/skills/papel-*) em vez da fonte agents/.
  • Fazer o init sobrescrever; pôr skills: no frontmatter gerado; @import no AGENTS.md.
  • Furar o lint sem linha em .contexto-allow; gh pr merge, force push ou ssh fora de infra/deploy (o hook barra).

Como fazer

Testar e checar contexto (antes de todo commit)

npm test                 # node --test test/*.test.mjs
npm run lint:contexto    # inegociáveis 10 e 11
npm run guia:check       # caminhos e âncoras deste guia

Abrir este guia

npm run guia             # http://127.0.0.1:4318/ com catálogo e estado ao vivo
xdg-open docs/guia-de-desenvolvimento/index.html   # file://, sem catálogo/estado

Adotar num projeto

cd ~/meu-projeto
npx github:Pa1loh/PadraoAI init      # nunca sobrescreve
# depois, ao agente: "leia docs/padraoai/ADOTAR.md e adote o padrão"

Mudar um papel e regenerar

Edite a fonte em agents/ (corpo ≤25 linhas) e a matriz "Quem acessa o quê" em agents/README.md; teste em test/agents-sync.test.mjs.

node bin/agents-sync.mjs /caminho/do/projeto     # ou: npx github:Pa1loh/PadraoAI agents

Criar uma skill

  1. Decida o lugar: workflow do padrão → skills/; opcional → extras/skills/; só de um projeto → .claude/skills/ do projeto. Já existe parecida? Estenda.
  2. Frontmatter com name e description de 1 linha com gatilhos; ≤120 linhas.
  3. Se o init/agents distribui: entra em files do package.json e em SKILLS_DE_FLUXO de bin/agents-sync.mjs.
  4. Atualize o mapa do README.md e o CATALOGO-SOB-DEMANDA.md. O catálogo deste guia se atualiza sozinho.

Ligar/desligar skill só num projeto

bin/skill-on agent-browser /caminho/do/projeto
bin/skill-off agent-browser /caminho/do/projeto

Adicionar um hook

Script em templates/.claude/hooks/ (saída 2 = bloqueia), registro em templates/.claude/settings.json e em dsh/hooks.json (o teste exige os mesmos), caso bom e ruim em test/agents-sync.test.mjs. Hooks no dsh, uma vez por máquina:

node bin/dsh-setup.mjs

Ver ou editar engine por papel

node bin/padraoai.mjs engines plano templates/docs/engines.yml
npx github:Pa1loh/PadraoAI engines --abrir        # no projeto: edita docs/engines.yml

Entregar (PR)

Branch própria (feat/…, fix/issue-N-slug), PR pequeno com uma intenção, CI verde. Merge em master = publicado (ver superfície pública).
